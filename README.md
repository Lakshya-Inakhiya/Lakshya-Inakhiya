## 🚀 Featured Projects

### 🤖 Ash

<a href="https://github.com/Lakshya-Inakhiya/Ash">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Lakshya-Inakhiya&repo=Ash&theme=dracula&bg_color=0a192f&title_color=00cdff&icon_color=00cdff&text_color=e6f1ff&border_color=00cdff&v=3" alt="Ash"/>
</a>

A little robot you can talk to. Speak or type, and Ash answers using AI, then reacts with an animated face and arms: it waves when you say hi, points when you ask a question and cheers at good news. It began as my first-semester project, a physical robot on a Raspberry Pi 5 with an LCD face and servo arms. I later split it into one shared "brain" with two bodies, so the same logic drives both the real robot and a web version anyone can try.

| Layer | Technology |
|-------|------------|
| Brain | Python: replies, face and gesture choice, model fallback |
| AI | Groq (OpenAI-compatible API), Whisper speech-to-text, edge-tts voice |
| Web | Gradio, animated SVG avatar, deployed on Render |
| Hardware | Raspberry Pi 5, ILI9486 SPI LCD driver, PCA9685 servo control |
| Quality | pytest, GitHub Actions CI |

🔗 **Live:** [ash-11nq.onrender.com](https://ash-11nq.onrender.com) &nbsp;|&nbsp; 💻 **Code:** [github.com/Lakshya-Inakhiya/Ash](https://github.com/Lakshya-Inakhiya/Ash)

### 📐 math-pdf-builder

<a href="https://github.com/Lakshya-Inakhiya/math-pdf-builder">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Lakshya-Inakhiya&repo=math-pdf-builder&theme=dracula&bg_color=0a192f&title_color=00cdff&icon_color=00cdff&text_color=e6f1ff&border_color=00cdff&v=3" alt="math-pdf-builder"/>
</a>

Converts Markdown notes full of LaTeX math into clean, styled PDF study guides and solution sets, with KaTeX rendering fully offline. Started as the tool I used to build discrete math study guides for my IIT Delhi coursework.

| Layer | Technology |
|-------|------------|
| Core | Python (`pathlib`, `re`) |
| Math rendering | KaTeX (local, offline) |
| Layout | HTML + CSS templates |
| Output | Headless Chromium (Playwright) |

🔗 **Live:** — &nbsp;|&nbsp; 💻 **Code:** [github.com/Lakshya-Inakhiya/math-pdf-builder](https://github.com/Lakshya-Inakhiya/math-pdf-builder)

### 🧮 dsa-practice

<a href="https://github.com/Lakshya-Inakhiya/dsa-practice">
  <img src="https://github-readme-stats.vercel.app/api/pin/?username=Lakshya-Inakhiya&repo=dsa-practice&theme=dracula&bg_color=0a192f&title_color=00cdff&icon_color=00cdff&text_color=e6f1ff&border_color=00cdff&v=3" alt="dsa-practice"/>
</a>

Data structures and algorithms written from scratch: quick/merge/heap sort, hashing, and a stack of matrix and recursion problems (spiral matrix, layer rotation, sparse matrix, Tower of Hanoi, permutations), plus C++ fundamentals.

| Layer | Technology |
|-------|------------|
| Languages | Python, C++ |
| Structures | Heaps, hash maps, stacks, sparse matrices |
| Algorithms | Sorting, recursion, matrix manipulation |
| Tooling | VS Code, Git |
